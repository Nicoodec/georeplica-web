# GeoReplica — prototipo web

Prototipo de web para GeoReplica Technologies (gemelos digitales). Una figura humana hecha de 0 y 1, animada en 3D, guía la página.

- `npm install` y `npm run dev` para desarrollar.
- `npm run build` genera `dist/`.
- Sin internet: doble clic en `ABRIR PAGINA.bat` (Windows).
- Cada push a `main` se publica solo en GitHub Pages.

Modelo 3D: maniquí *Xbot* de los ejemplos de three.js (Mixamo).
